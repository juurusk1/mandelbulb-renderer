# Mandelbulb 

Real-time Mandelbulb renderer written in Python, ModernGL and Pygame.

## Features

- Raymarched Mandelbulb
- Orbital camera
- Dynamic LOD
- Custom color palettes
- Animated DE power

## Controls

- Left mouse drag: orbit camera
- Mouse wheel: zoom
- Esc: quit"# mandelbulb-renderer"
